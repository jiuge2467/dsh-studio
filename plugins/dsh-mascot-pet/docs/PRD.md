# 小鲸鱼姬桌宠与摸鱼伴侣插件 (PRD)

> **文档版本**: V1.0
> **适用范围**: DeepSeek Harness (DSH) 插件生态体系

---

## 1. 背景与目标
在沉浸式全栈开发中，开发者面临长时间高强度思考与编码压力。小鲸鱼姬作为 DeepSeek 官方专属萌宠，通过 Cordis 驱动的插件化架构，将 Q 版桌面伴侣、实时计费监控、英语四级闯关与摸鱼解压游戏完整打包为独立插件，实现零侵入、即插即用的体验。

---

## 2. 功能清单 (P0 / P1)
- **P0-1 双端 Cordis 插件架构**：Host 提供 Service 与 Tool，Client 自动挂载浮层；
- **P0-2 透明桌宠交互**：支持自由拖拽与记忆、Agent 状态联动（呼吸高亮/开心/待命）；
- **P0-3 5 大伴侣功能 Tab**：用量账单、CET-4 乱序背单词、摸鱼消消乐、美食大转盘、极客段子；
- **P0-4 模型主动互动**：支持 `pet_interact` 工具；
- **P1-1 跨平台一键安装**：提供 `install.ps1` 与 `install.sh`。

---

## 3. EARS 验收标准
- **EARS-01**：*WHEN* 用户拖拽桌宠到任意屏幕位置并释放，*THEN* 系统保存坐标并在下次启动时保持在该位置；
- **EARS-02**：*WHEN* 用户点击桌宠头像，*THEN* 展开包含 5 个功能 Tab 的伴侣面板，点击右上角 ✕ 瞬间收起；
- **EARS-03**：*WHEN* Agent 开始深度思考时，*THEN* 桌宠呈现呼吸发光动画并显示思考秒数气泡。
