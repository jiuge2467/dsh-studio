# 小鲸鱼姬 2.0「摸鱼游戏中心 & Web Audio 音效 & 亲密度联动」完整产品需求与架构方案 (PRD & ARCH)

> **版本**：v2.2
> **制定团队**：PM、ARCH、DEV、QA、OPS 联合研讨
> **核心目标**：实现“小而精”的内置原生摸鱼小游戏库，集成 Web Audio 纯代码合成音效，打通游戏得分与小鲸鱼姬亲密度（好感度）深度养成体系。

---

## 一、 需求背景与竞品分析 (PM)

### 1.1 现状分析与痛点
1. **Iframe 报错问题**：原 2048 和打砖块使用外部 Iframe 导致 `forbidden` 403 权限错误，必须彻底改为 React / Canvas 原生实现。
2. **UI 细节暗色背景文字对比度**：原「戳水泡」首页副标题在暗黑背景下因继承了默认深色文本导致看不清，需要统一定制霓虹高对比配色。
3. **缺少听觉反馈**：缺乏音效反馈使得游戏打击感和互动沉浸感不足。
4. **游戏与桌宠割裂**：小游戏目前仅停留在“玩”，没有与小鲸鱼姬的亲密度/好感度/饱腹感/台词互动产生正向循环。

### 1.2 竞品参考与特色提炼
* **参考对象**：
  * **QQ宠物 / 桌面萌宠**：游戏获得经验/体力/好感度，增加与桌宠的羁绊。
  * **赛博朋克 / 极光风格小游戏**：霓虹光效、粒子爆破、清脆 8-bit/Synth 音效。
  * **Google Chrome Dino / 微信跳一跳**：即开即玩、零加载时间、手感丝滑。

### 1.3 功能矩阵与优先级 (P0 / P1)

| 模块 | 功能项 | 优先级 | 描述 |

### 2.2 Web Audio 零依赖音效引擎 (`MascotSoundEngine.ts`)

为了避免音频文件 404、跨域或加载延迟，采用 Web Audio API 的正弦波 (`sine`)、方波 (`square`)、三角波 (`triangle`) 与白噪声实时生成音效：
* `pop()`: 400Hz → 800Hz 快速正弦滑频 + 指数衰减（水泡破裂声 🫧）
* `slide()`: 200Hz 低频短促白噪 + 柔和包络（2048 方块滑动）
* `merge()`: 523Hz(C5) + 659Hz(E5) 双音和弦钟鸣（2048 合并）
* `hit()`: 440Hz 短促三角波（打砖块弹球撞击）
* `brickBreak()`: 300Hz 调频晶体碎裂音（砖块击碎）
* `powerup()`: 上行三连音 Arpeggio（拾取道具）
* `levelUp()` / `victory()`: 欢快 C 大调琶音（升级/高分达成）
* `muted` 状态全应用一键持久化开关。

### 2.3 好感度结算体系 (Affection Economy)

1. **戳水泡**：
   - 基础得分：常规水泡 +10分、小鲸鱼 +30分、钻石 +50分。
   - 连击加成：3s 内连续点击触发 Combo (最高 3x)。
   - 好感度结算：`Math.floor(score / 50)`，每局上限 +15 好感度。
2. **2048 极光**：
   - 合成 128: +2 好感度；合成 512: +5 好感度；合成 2048: +20 好感度。
   - 游戏结束结算：`Math.floor(score / 100)`，单局上限 +25 好感度。
3. **霓虹打砖块**：
   - 每消除一层砖块 +2 好感度，通关奖励 +20 好感度。
   - 游戏结束结算：`Math.floor(score / 30)`，单局上限 +20 好感度。
4. **桌宠互动反馈**：
   - 结算时小鲸鱼姬头上弹出获得好感度数值与爱心飞扬动效。
   - 小鲸鱼姬触发专属语音台词与跳跃庆祝。

## 三、 模块详细设计 (DEV)

### 3.1 `Aurora2048.tsx` (2048 极光)
- **网格算法**：纯 TypeScript 实现标准的 4x4 2048 算法（左/右/上/下 移动、滑动合并、随机生成 2 或 4、死局与胜利判定）。
- **历史记录栈**：保持上一步状态，提供 Undo（悔棋）功能。
- **渲染设计**：
  - 数字背景：
    - 2: `#1e293b`, 4: `#0284c7`, 8: `#0ea5e9`, 16: `#10b981`, 32: `#f59e0b`, 64: `#f97316`, 128: `#ef4444`, 256: `#ec4899`, 512: `#8b5cf6`, 1024: `#6366f1`, 2048: `linear-gradient(135deg, #ec4899, #8b5cf6, #3b82f6)` 炫彩流光。
- **尺寸自适应**：精准适配 310px 宽度，在小鲸鱼姬面板中完美居中显示，包含迷你虚拟摇杆/方向按键。

### 3.2 `NeonBreakout.tsx` (霓虹打砖块)
- **Canvas 渲染**：`canvas width="310" height="260"`，高清 Retina DPR 适配。
- **物理循环**：`requestAnimationFrame` 驱动。
- **元素**：
  - 挡板：发光渐变圆角矩形，支持鼠标跟随、左右按键与触摸滑动。
  - 弹球：带尾迹发光粒子。
  - 砖块：5 行 7 列，多种颜色与分值。
  - 道具 Buff：绿球（多球分裂）、蓝光（挡板变长 1.5 倍）。

### 3.3 `BubbleGame.tsx` (优化版)
- **视觉优化**：修复文字颜色为亮白 `#f8fafc` + 霓虹发光字幕；
- **声效接入**：点击水泡播放 `pop()` 泡泡音效，获得宝石播放闪耀音效；
- **粒子喷射**：点击位置散落彩色小气泡碎屑。
