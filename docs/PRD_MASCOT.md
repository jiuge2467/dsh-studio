# PRD: DeepSeek 小鲸鱼姬桌宠与设置中心插件 (dsh-mascot-pet)

> **文档性质**：Product Requirement Document (PRD)
> **责任角色**：🎯 PM（产品经理）
> **关联项目**：`dsh-mascot-pet` → 集成至 DeepSeek Harness Web Profile
> **当前阶段**：Phase 1: PRD & Scope (待用户确认)

---

## 1. 需求四问 (Product Discovery)

| 维度 | 描述 |
| :--- | :--- |
| **目标用户 (Who)** | 使用 DeepSeek Harness 进行高强度编程、日常多智能体协作、长时间调试的开发者。 |
| **核心场景 (When & Where)** | 1. 编码与思考时，右下角有透明 Q 版小鲸鱼姬桌宠陪伴，根据 Agent 运行状态（思考/活跃/闲置）做出表情反馈；<br>2. 长时间编码疲劳时，桌宠提供摸鱼解压（四级单词挑战、消消乐、美食大转盘、讲笑话）；<br>3. 用户点击左下角【设置】弹窗时，在左侧导航栏看到专属【小鲸鱼姬】设置分区，可自由调节桌宠开关、形象换装预设、互动频率等。 |
| **解决痛点 (Pain Point)** | 长时间面对冰冷终端与代码容易疲劳；缺乏生动有趣的状态视觉反馈；插件设置分散，缺乏类似「侧边卡片」的标准设置入口。 |
| **设计参考 (Reference)** | `DSH-better-sidebar` 的 `settings.section` 声明式设置扩展标准、VSCode 插件独立设置页、Live2D/Shimeji 桌面伴侣。 |

## 2. 功能范围与优先级矩阵 (Scope Matrix)

### 🎯 P0（本次必须交付核心功能）
- [x] **P0-1 设置页专属分区「小鲸鱼姬」**：
  - 在 DSH 设置弹窗左侧导航栏注册 `小鲸鱼姬` 分区（`id: 'mascot-pet'`, `order: 110`）。
  - 继承 DSH 原生表单设计语言，提供：
    1. **桌宠总开关**：一键显示/隐藏小鲸鱼姬浮层（状态持久化）。
    2. **换装与外观预设（预留扩展区）**：提供默认女仆装（Classic Maid）、夏日水手服（Summer Sailor）、赛博极客（Cyber Geek）等皮肤卡片预设展示。
    3. **互动与气泡频率**：高频 / 适中 / 专注免打扰模式切换。
    4. **摸鱼功能开关**：四级单词、美食转盘、解压气泡功能独立启用/停用。
- [x] **P0-2 透明桌宠浮动挂载与状态感知**：
  - 自由拖拽与位置记忆（LocalStorage）。
  - 感知 Agent 运行（Running 呼吸与思考态、Idle 闲置呼吸态、点击欢呼态）。
  - 点击弹出摸鱼面板（Token 仪表盘、单词游戏、美食轮盘等）。
- [x] **P0-3 DSH Profile 完整集成与挂载**：
  - 完善 `package.json`、`cordis.patch.yml`、TypeScript 编译规范。
  - 通过 `dsh plugin --profile web add ./dsh-mascot-pet` 自动挂载至 DSH Web Profile。

## 3. 验收标准 (EARS 规范)

- **[EARS-1: 设置入口]**
  *WHEN* 用户点击 DSH 界面左下角的【设置】按钮
  *THEN* 设置弹窗左侧导航栏应包含【小鲸鱼姬】选项，点击后右侧展示小鲸鱼姬专属配置面板。
- **[EARS-2: 独立开关]**
  *WHEN* 用户在设置中关闭【启用桌面伴侣】开关
  *THEN* 屏幕右下角的小鲸鱼姬桌宠应平滑隐藏，且刷新页面后保持隐藏状态。
- **[EARS-3: 换装与外观预设]**
  *WHEN* 用户在小鲸鱼姬设置面板中浏览【形象与装扮】
  *THEN* 应展示规范的皮肤预设卡片与未来扩展标识，支持选择默认皮肤。
- **[EARS-4: 桌宠互动与摸鱼中心]**
  *WHEN* 用户点击小鲸鱼姬身体
  *THEN* 应触发欢呼表情并弹出摸鱼中心弹窗，支持拖拽移动桌宠位置。
- **[EARS-5: 全量构建与热加载]**
  *WHEN* 运行 `pnpm dsh web` 并访问 `http://127.0.0.1:3080`
  *THEN* 小鲸鱼姬桌宠与设置页面应正常加载，控制台无报错。
