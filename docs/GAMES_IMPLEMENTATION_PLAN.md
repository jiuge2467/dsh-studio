# 小鲸鱼姬 2.0「摸鱼挑战」迷你游戏中心开发方案与架构设计

> **版本**：v2.1
> **模块**：`dsh-mascot-pet` -> `src/client/modules/`
> **目标**：彻底消除 iframe 403 依赖，基于原生 React & HTML5 Canvas 全新研发并无缝集成「2048 极光」与「霓虹打砖块」两大高互动性休闲小游戏。

---

## 1. 现状问题与改造目标

### 1.1 现状分析
- **问题根因**：当前 `BubbleGame.tsx` 中，「2048 极光」和「打砖块」子 Tab 采用外部 `iframe` 跨域或绝对路径引用 `http://127.0.0.1:3080/api/studio/files/raw?...`，导致浏览器直接提示 **`forbidden`**（无法加载或缺少权限）。
- **体验缺失**：外部页面样式割裂、不支持触屏/手势、无法与小鲸鱼姬的好感度与状态机体系联动。

### 1.2 改造目标
1. **100% 原生轻量化组件**：使用纯 React / TypeScript 与 HTML5 Canvas 原生实现，零外部 iframe 依赖。
2. **美学设计与深色适配**：采用 Cyber/Glassmorphism 霓虹琉璃暗黑质感，完美贴合 DSH 整体 UI 风格。
3. **多端交互支持**：
   - **2048 极光**：支持键盘方向键/WASD、滑动触摸、触控按钮三种操作方式；
   - **霓虹打砖块**：支持鼠标跟随、左右按键与触摸拖拽挡板，平滑 60 FPS 物理碰撞演算。
4. **游戏机制与养成联动**：
   - 得分排行榜与本地最高纪录持久化 (`localStorage`)；
   - 游戏获胜/得分可喂养小鲸鱼姬、增加好感度与触发专属庆祝台词。

## 2. 详细功能设计

### 2.1 游戏一：2048 极光 (`Aurora2048.tsx`)

#### 🎮 核心玩法与特色
* **4x4 极光数字棋盘**：
  * 每个数字具有专属的霓虹渐变色彩（2: 蓝灰、4: 冰蓝、8: 青绿、16: 金黄、32: 珊瑚橙、64: 洋红、128~1024: 极光渐变发光、2048: 炽热霓虹金光特效）。
* **流畅滑动与合并动画**：
  * 网格合并带有弹性缩放与微光涟漪特效。
* **操作控制**：
  * **键盘**：`ArrowUp` / `ArrowDown` / `ArrowLeft` / `ArrowRight` 或 `W / A / S / D`。
  * **触控/鼠标**：提供方向键按钮盘与手指滑动手势支持。
* **撤销与重开**：
  * 支持 1 步「悔棋 (Undo)」功能与一键重新开局。
* **战绩与好感度**：
  * 自动记录 Highest Score；
  * 合成 256/512/1024/2048 触发小鲸鱼姬专属喝彩。

### 2.2 游戏二：霓虹打砖块 (`NeonBreakout.tsx`)

#### 🎮 核心玩法与特色
* **Canvas 60FPS 丝滑物理引擎**：
  * 精确的球-板、球-砖块、球-边界弹性反射物理算法。
  * 挡板击球点偏角机制（击中板边缘反射角变大，增加可玩性）。
* **多层彩虹霓虹砖块**：
  * 4~5 排不同分值与颜色的发光砖块。
  * 击碎砖块触发粒子飞溅特效。
* **道具与 Buff 掉落机制**：
  * 🟢 **双倍弹球**（Multi-ball）
  * 🔵 **加长挡板**（Long Paddle）
  * ⚡ **镭射穿透**（Laser Penetrate）
* **生命与得分系统**：
  * 3 颗心初始生命，支持暂停/继续与重新开始。
  * 通关/闯关得分计入最高分。

### 2.3 游戏中心导航与整合 (`GameCenter.tsx`)
* 将 `BubbleGame` 重构/组合为标准游戏中心，包含三个独立原生子模块：
  1. `🫧 戳水泡` (BubbleGame - 已支持)
  2. `🔢 2048 极光` (Aurora2048 - 全新原生)
  3. `🧱 霓虹打砖块` (NeonBreakout - 全新原生)
