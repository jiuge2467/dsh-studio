## 一、 需求背景与痛点

目前我们的小鲸鱼姬已具备 3 套高质量纯透明 Q 版皮肤（经典女仆、赛博极客、夏日水手）、Token 实时计费和摸鱼解压小游戏。然而目前的立绘展示仍以 **CSS 浮动静态图（Idle 呼吸 + Happy 摸头）** 为主，相比于经典的 **QQ 宠物**、华硕 **天选姬 (Tianxuan Ji)**、**vscode-pets** 等桌面伴侣，还缺乏：
1. 🎭 **会话状态深度联动**：在 AI 思考、吐字、工具调用、完成、报错时，缺乏生动的专属肢体动作；
2. 🚶 **自主漫步与随机微动作**：闲置时固定在原地，缺少自主游动踱步、打瞌睡、伸懒腰等灵动感；
3. 🐾 **丰富的物理触摸反馈**：缺少被拎起在空中扑腾腿、投喂吃零食、眼神跟随等物理交互。

## 二、 现有项目源码深度解析 (`dsh-web-ui/packages/dsh-pet`)

我们深度剖析了本地 `dsh-web-ui` 仓库中 `dsh-pet`（鲸鱼娘宠物）的原生实现机制：

```
                              ┌────────────────────────────────────────────────────────┐
                              │             DSH 会话持久化事件流 (SessionEvents)        │
                              └──────────────────────────┬─────────────────────────────┘
                                                         │ turn/start, chunk, tool/call, turn/end
                                                         ▼
                              ┌────────────────────────────────────────────────────────┐
                              │           官方事件映射器 (event-projection.ts)          │
                              └──────────────────────────┬─────────────────────────────┘
                                                         │ 转换为 7 种 Phase 状态
                                                         ▼
┌──────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│                            Codex 9 状态动作状态机 (state.ts / spritesheet.ts)                                 │
├──────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│  0: idle (待机呼吸)          1: running-right (右向奔跑)     2: running-left (左向奔跑)                      │
│  3: waving (挥手打招呼)      4: jumping (完成欢呼跳跃)       5: failed (报错眩晕/抓狂)                       │
│  6: waiting (等待输入)       7: running (敲代码/黑客思考)    8: review (整理回复/看书)                       │
└──────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

* **核心优势**：
  1. 纯声明式的会话事件监听（通过 DSH 官方持久化事件流驱动），零性能损耗；
  2. 使用 `requestAnimationFrame` 驱动 8 帧/轨的高性能 Spritesheet 渲染；
  3. 具备投喂（Feeding）、抚摸（Petting）、拖拽边界限制（Clamping Drag）逻辑。

## 三、 GitHub 生态与开源技术栈调研

通过对 GitHub 上相似技术栈（React / TypeScript / CSS Sprites / Canvas / Live2D）开源桌面宠物项目的调研，主流实现方案如下：

| 项目 / 生态 | 技术栈 | 核心特色 | 适用性与优缺点 |
| :--- | :--- | :--- | :--- |
| **vscode-pets**<br>*(tonybaloney)* | TypeScript + Canvas / Sprite 序列帧 | 经典漫步算法（Wander Engine）、抛球捡球、小范围追逐玩耍、多种状态动作。 | ⭐⭐⭐⭐⭐ **极其契合**。纯轻量级 JS 物理引擎，零重型依赖，适合在 Web 中小范围漫步。 |
| **OpenPets / Petdex**<br>*(openpets/crafter-station)* | TypeScript + Codex 8×9 Atlas 协议 | 针对 Coding Agent（Claude/DeepSeek）设计的桌面伴侣协议，与 DSH 原版标准 100% 对齐。 | ⭐⭐⭐⭐⭐ **原生对齐**。可直接复用其动作状态机与会话联动事件标准。 |
| **ViviPet / Copiwaifu** | React + Live2D Cubism 5 | Live2D 骨骼动画、眼球注视追踪、口型同步。 | ⭐⭐⭐ 表现力极强，但需要 Live2D 模型专属动作文件（.model3.json），资产制作门槛高。 |
| **Tamago-AI** | React + CSS Sprite / Box-Shadow | 纯 CSS / Web Component 驱动轻量级虚拟桌宠，低内存占用。 | ⭐⭐⭐⭐ 适合轻量化 Web UI 嵌入。 |

## 四、 升级产品方案：小鲸鱼姬 2.0 灵动交互系统

我们将融合 **vscode-pets 的漫步算法** 与 **OpenPets 的会话状态机**，打造具有“天选姬”级别灵动度的小鲸鱼姬！

```
                                  ┌────────────────────────────────┐
                                  │      小鲸鱼姬 2.0 灵动交互引擎   │
                                  └───────────────┬────────────────┘
                                                  │
                 ┌────────────────────────────────┼────────────────────────────────┐
                 │                                │                                │
                 ▼                                ▼                                ▼
  【1. 会话状态深度动作联动】           【2. 自主漫步与随机微动作】           【3. 物理互动与成长投喂】
   • 思考：敲键盘 / 全息光幕               • 范围游动：80~150px 游弋漂浮         • 拎起挣扎：拖拽时扑腾小短腿
   • 吐字：手舞足蹈 / 翻看笔记             • 闲置微动作：打瞌睡、伸懒腰、吹泡泡   • 摸摸头：冒爱心欢呼、专属语音
   • 工具：拿扳手维修 / 查文件             • 眼神跟随：视线随鼠标指针移动        • 投喂：喂食奶茶蛋糕，提升好感度
   • 成功：撒花跳跃比心                   • 避障回弹：遇到窗口边缘自动折返      • 换装：3 款皮肤专属动作套件
   • 报错：抓狂晕倒顶问号
```

### 1. 状态动作矩阵 (State-Action Matrix)

| Agent 行为 / 用户交互 | 小鲸鱼姬动作表现 | 视觉特效与气泡 |
| :--- | :--- | :--- |
| **闲置就绪 (Idle)** | 浮动呼吸、微微眨眼、摇摆尾巴 | 气泡：“开发者你好！今天想写点什么呢~” |
| **自主漫步 (Wander)** | 在底部 120px 范围内慢慢游动漂移，遇边折返 | 偶尔冒出蓝色小水泡 |
| **闲置微动作 (Random Perks)** | 随机触发：打瞌睡呼噜（Zzz）、喝奶茶、伸懒腰 | 头顶浮现 `(。-ω-)zzz` 或 🧋 奶茶小图标 |
| **思考中 (Thinking)** | **极客**：疯狂敲键盘；**女仆**：托腮认真思考；**水手**：转笔 | 呼吸发光 Glow + 实时 TPS 速率跳动 |
| **工具调用中 (Tool Running)** | 拿出扳手维修齿轮 / 拿着放大镜查阅文件 | 气泡：“正在使用 `bash` 跑测试用例~” |
| **整理回复 (Streaming)** | 翻看代码本，快速点头汇报 | 气泡：“代码整理中，马上就好啦~” |
| **完成撒花 (Done/Celebration)** | 开心跳跃、挥手比心、原地转圈 | 撒花彩带特效 + 气泡：“完成啦！快来看看~” |
| **报错/中断 (Failed/Error)** | 趴倒晕倒、双眼冒蚊香圈、抓狂 | 冒冷汗 `(；´д｀)ゞ` + 气泡：“哎呀，遇到错误了…” |
| **鼠标悬停 (Hover)** | 身体微微前倾，眼神朝鼠标指针方向看 | 脸颊浮现红晕 |
| **拖拽抓起 (Drag in Air)** | 身体悬空，小短腿在空中可怜巴巴扑腾 | 挣扎表情，松手时弹性缓动落回 |
| **点击抚摸 (Pet Head)** | 享受地眯起眼睛，头顶升腾粉色爱心 | 弹出治愈语录 + 好感度 +1 |
| **投喂食物 (Feeding)** | 捧着甜甜圈/西瓜大口吃，满足鼓脸颊 | 饱腹感提升 + 专属吃货语录 |

### 2. 核心技术实现路径

1. **自主漫步引擎 (Wander Engine)**：
   - 采用平滑 Bezier / 正弦波漂浮游动算法，在以原点为中心的 `[-120px, +120px]` 限制区域内自主游弋；
   - 具有朝向判定（向左游翻转 `scaleX(-1)`，向右游 `scaleX(1)`）；
   - 在用户发起对话、拖拽或点击时立即打断漫步，平滑回到交互状态。
2. **多皮肤帧序列与动作映射 (Multi-Skin Frame Pipeline)**：
   - 针对当前 3 款皮肤（经典女仆、赛博极客、夏日水手），建立标准的帧序列与动作状态机；
   - 无缝衔接当前已有的 Token 计费、四级单词挑战与摸鱼解压中心。
3. **物理拖拽悬空状态 (Air Hang Physics)**：
   - 捕获 `PointerDown` 拖动超过阈值时，自动切换为“被抓起”悬空动作；
   - `PointerUp` 时应用惯性与缓动重力（Easing Spring），优雅定格。

## 五、 实施计划与分步交付

* **阶段 1（资产与状态机骨架）**：
  - 接入标准 7 状态会话事件探针（Thinking / Tool / Review / Done / Failed / Waiting / Idle）。
  - 实现拖拽悬空扑腾、摸头冒爱心与眼神跟随响应。
* **阶段 2（自主漫步与随机微动作）**：
  - 实现 120px 范围自主游弋漫步引擎与边界智能避障回弹。
  - 加入闲置 15~30s 随机打瞌睡、伸懒腰、吹泡泡微动作。
* **阶段 3（投喂系统与好感度成长）**：
  - 在伴侣中心增加【投喂零食】按钮（奶茶、西瓜、甜甜圈），丰富互动趣味性。
