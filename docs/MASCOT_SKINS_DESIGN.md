## 4. 技术资产打包与存储规范 (Technical Asset Spec)

1. **资产标准化打包** (`mascot-skins-assets.ts`)：
   - 将 3 套皮肤的 `idle` 与 `happy/cheer` 高保真立绘进行高精度透明背景抠图与优化。
   - 分别编码为高画质轻量 Base64 DataURI 导出：
     - `CLASSIC_SKIN`: `{ idle, happy, name: '经典女仆', tag: 'Classic' }`
     - `GEEK_SKIN`: `{ idle, happy, name: '赛博极客', tag: 'Geek' }`
     - `SAILOR_SKIN`: `{ idle, happy, name: '夏日水手', tag: 'Sailor' }`
2. **状态持久化**：
   - 换装选择通过 `localStorage.getItem('dsh_mascot_skin') || 'classic'` 实现毫秒级热切换与持久化，换肤无需重启服务。
