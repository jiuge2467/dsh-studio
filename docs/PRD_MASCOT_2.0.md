# PRD: 小鲸鱼姬 2.0 灵动交互与自主漫步桌面伴侣系统 (Mascot 2.0 Dynamic Suite)

> **责任角色**：🎯 PM（产品经理）
> **适用模块**：`dsh-mascot-pet` (DeepSeek Harness 桌面宠物微前端插件)
> **版本**：v2.0.0

## 1. 需求四问 (Product Requirements 4-Questions)

### 1.1 目标用户 (Target Users)
* 使用 DeepSeek Harness 进行长周期编码、自动化流程调试与高强度开发的全栈工程师。
* 喜爱拟人化陪伴、桌宠互动、治愈解压交互的开发者与二次元桌面文化爱好者。

### 1.2 核心场景 (Core Scenarios)
1. **会话全生命周期肢体动作反馈**：
   - 当大模型开始思考、消耗 Token 且 TPS 高速吞吐时，小鲸鱼姬呈现专注工作姿态（敲键盘/全息操作）；
   - 当调用 Bash / 文件读写等工具时，小鲸鱼姬拿出扳手修理齿轮/放大镜查阅文件，并弹出工具气泡；
   - 当回答生成完毕时，小鲸鱼姬开心地跳跃、挥手撒花比心；遇到报错时眩晕趴地冒蚊香圈。
2. **闲置时自主游弋漫步与随机微动作**：
   - 无对话闲置时不再呆板固定站立，而在屏幕底部/停靠区域 `[-120px, +120px]` 范围内轻盈缓动游弋，遇到边缘平滑转身；
   - 闲置 15~30 秒随机触发打瞌睡 `(。-ω-)zzz`、伸懒腰、吹蓝色水泡。
3. **物理触控与被拎起悬空挣扎**：
   - 鼠标按住拖拽时，小鲸鱼姬切换为“被拎住后颈皮在空中扑腾小短腿”的呆萌挣扎姿态，松开后弹性缓动落回目标位置；
   - 鼠标悬停时身体微倾、眼神跟随指针；点击抚摸头部升腾粉色爱心与专属治愈语录。
4. **投喂成长与好感度体系**：
   - 在伴侣中心新增【投喂零食】（奶茶、西瓜、甜甜圈），小鲸鱼姬大口吃掉并提升好感度与饱腹感。

### 1.3 解决痛点 (Pain Points Solved)
* **痛点 1（呆板无生气）**：原本只有静态图片呼吸和单调摸头，缺乏类似天选姬、QQ 宠物、vscode-pets 的灵动游动感。
* **痛点 2（与 AI 编码脱节）**：AI 正在执行复杂的工具或长思考时，桌面伴侣没有对应的肢体动作状态呼应。
* **痛点 3（互动维度单一）**：拖拽时无物理反馈，缺乏投喂、好感度、眼神交互等长效陪伴机制。

### 1.4 业界优秀参考 (Industry Benchmarks)
* **华硕天选姬 (Tianxuan Ji)**：多状态动作切换、桌面自由漫步、待机趣味微动作、鼠标触摸交互。
* **vscode-pets**：轻量级漫步算法（Wander Engine）、边界避障物理反弹、投喂互动。
* **OpenPets / Codex Atlas**：Coding Agent 生命周期（Thinking/Tool/Review/Done/Failed）与 9-Track 动作状态机标准化映射。

## 3. EARS 验收标准 (Easy Approach to Requirements Syntax)

* **EARS-1 (会话动作响应)**：*WHEN* 大模型开始流式输出思考/消耗 Token 时，*THE SYSTEM SHALL* 在 < 100ms 内从小鲸鱼姬当前姿态平滑切换为对应皮肤的【专注敲键盘/操作光幕】动作，并展示实时 TPS 动态光效。
* **EARS-2 (工具调用反馈)**：*WHEN* Agent 发起工具调用（如 bash / run_command / view_file）时，*THE SYSTEM SHALL* 切换为【工具检修姿态】并在状态气泡显示对应工具名称。
* **EARS-3 (自主漫步与打断)**：*WHEN* 宠物处于闲置状态超过 5 秒且用户未操作时，*THE SYSTEM SHALL* 启动小范围自主游弋；*WHEN* 用户点击、拖拽或 Agent 发起新会话时，*THE SYSTEM SHALL* 立即优雅打断漫步并无缝切入交互姿态。
* **EARS-4 (悬空拖拽物理反馈)**：*WHEN* 鼠标按下并拖拽超过 5px 阈值时，*THE SYSTEM SHALL* 切换为【悬空扑腾小短腿】姿态；*WHEN* 释放鼠标时，*THE SYSTEM SHALL* 恢复站立姿态。
* **EARS-5 (投喂与好感度)**：*WHEN* 用户在面板中点击投喂零食时，*THE SYSTEM SHALL* 播放吃零食特效，好感度 +5、饱腹感 +20，并本地持久化。
